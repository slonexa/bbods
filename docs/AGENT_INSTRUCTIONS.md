# Инструкция для ИИ-Агентов (Agent Instructions)

Привет, коллега! Если ты читаешь этот файл, значит пользователь поручил тебе развивать или поддерживать проект арбитражного сканера. Пожалуйста, строго следуй этим правилам и контексту.

## Контекст проекта
Этот проект — сканер арбитражных вилок (спредов) между рынками предсказаний. Главный фокус текущей фазы — интеграция CEX платформ с новыми prediction-продуктами (Bybit Odds, MEXC, OKX Trade Events, Gate.com). На этих площадках часто нет публичного API, поэтому данные нужно добывать через реверс-инжиниринг их веб-клиентов.

## Архитектура
- **`collectors/`**: Модули парсинга. Каждый класс наследуется от `BaseCollector`.
- **`normalizer/`**: Матчинг событий. Пока используется ручной маппинг в `event_map.json`.
- **`engine/`**: Расчет профита. Учитываем комиссии (`fee_a`, `fee_b`) и проскальзывание (`slippage`). Пишет в `spreads.db`.
- **`dashboard/`**: FastAPI + ванильный JS, папка `static/`.

## Твои задачи (Как действовать)

1. **Если просят добавить платформу:**
   - Не ищи официальное API, если его нет (как у Bybit Odds). Попроси пользователя помочь найти внутренние XHR/Fetch запросы через DevTools.
   - Используй библиотеку **`curl_cffi`** (вместо обычного `requests`), чтобы обходить защиту Cloudflare/Akamai.
   - Изучи файл `docs/adding_platforms.md`.

2. **Если просят улучшить матчинг (Normalizer):**
   - Учитывай специфику 5-минутных контрактов (разные оракулы цен, рассинхрон во времени старта). 
   - Автоматический матчинг должен сверять: `Базовый актив` + `Тип контракта (Up/Down)` + `Точное время окончания` + `Источник цены (Оракул)`.

3. **Кодовая база:**
   - Сохраняй модульность. Не пиши расчеты в коллекторах. Коллектор только собирает и форматирует.
   - Дашборд должен оставаться простым (не тяни React/Vue, пока юзер явно не попросит).
   - При любых изменениях обновляй файл `CHANGELOG.md`.

4. **Запуск:**
   - Скрейпер запускается через `run.py`.
   - Дашборд запускается через `uvicorn dashboard.main:app`.
   - База данных SQLite (`spreads.db`) создается автоматически в корне.

## Общие принципы работы
Сначала исследуй код, потом предлагай решение. Опирайся на файлы в папке `docs/` и спецификацию `arbitrage-scraper-spec.md`. Удачи!
