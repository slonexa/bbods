# Архитектура проекта

Проект разбит на 4 независимых компонента. Обмен данными между ними стандартизирован, чтобы облегчить поддержку и добавление новых платформ.

## 1. Collectors (Сборщики)
Папка: `/collectors`

Отвечают за получение сырых котировок с площадок (через открытые API, внутренние/недокументированные эндпоинты, либо парсинг HTML/JS). 
- Наследуются от `BaseCollector`.
- Обязаны возвращать данные в строгом формате:
```json
{
  "platform": "имя_площадки",
  "market_id": "уникальный_id_рынка_и_исхода",
  "raw_title": "оригинальное название события",
  "outcome": "исход (например, Yes/No, Up/Down)",
  "implied_probability": 0.55,
  "expiry": "ISO-8601 время экспирации",
  "fetched_at": "ISO-8601 время сбора"
}
```

## 2. Normalizer (Нормализатор)
Папка: `/normalizer`

Так как на разных биржах одно и то же событие имеет разные ID (а иногда и разные формулировки), нормализатор отвечает за их сопоставление (matching).
- На этапе MVP используется ручной маппинг через файл `event_map.json`.
- Класс `Normalizer` загружает этот файл и ищет пересечения между списками событий с двух разных платформ.

## 3. Engine (Движок и Хранилище)
Папка: `/engine`

- **`spread.py`**: Считает чистый спред. Формула: `|ProbA - ProbB| - (FeeA + FeeB + Slippage)`. Если результат выше минимального порога (например, 0.02, т.е. 2%), событие считается арбитражной вилкой.
- **`db.py`**: Управляет локальной базой SQLite (`spreads.db`). Пишет найденные вилки в БД для истории, что позволяет анализировать частоту и размер спредов на дистанции.

## 4. Dashboard (Дашборд)
Папка: `/dashboard`

Отображает текущую ситуацию в браузере.
- Бэкенд написан на `FastAPI`.
- Фронтенд — чистый HTML/JS без фреймворков.
- Опрашивает API `/api/spreads` каждые 5 секунд и перерисовывает таблицу спредов, отсортированную по убыванию доходности.

## Точка входа (`run.py`)
Оркестратор, который крутится в бесконечном цикле:
1. Запрашивает данные у Collectors.
2. Отдает их в Normalizer.
3. Отдает совпадения в Engine.
4. Сохраняет результаты в DB.
5. Ждет `N` секунд и повторяет.
